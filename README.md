# Проект автоматизации тестирования сайта Яндекс.Самокат

1. Основа для написания автотестов — фреймворк pytest.
2. Установить зависимости — pip install -r requirements.txt.
3. Команда для запуска — pytest -v.
4. Для написания тестов используется фреймворк Selenium WebDriver.
5. Тесты настроены на драйвер для браузера Firefox.
6. Для отчетов по тестированию используется фреймворк Allure.
